Multi-Agent Quickstart / Working data pipeline

Give the team a dataset.

Four independent workers inspect, summarize, and validate a JSON dataset. This runs real computations in your browser, without an LLM or external data transmission. The workers use deterministic rules; they do not make autonomous judgments.

1 · Intake

Waiting for records.

2 · Quality

Checks missing fields and duplicates.

3 · Summary

Calculates numeric ranges and means.

4 · Validation

Reconciles counts and reports limitations.

Handoffs and result

Edit the sample or paste up to 2,000 JSON records.

Missing values remain visible. Numeric strings are not silently coerced. Duplicate records are reported, not deleted. This review checks data structure, not whether real-world claims are true.
